# 打造自己的呆萌型 AI 機器人

## 我的 AI：個人化保養與化妝品推薦助手

### 1. 我希望它解決什麼問題？

現在市面上的保養品和化妝品種類非常多，
同一類產品又有不同品牌、成分、價格和主打功效。

但每個人的膚質不一樣，
例如油性肌、乾性肌、混合肌或敏感肌，
適合的產品也不一定相同。

有時候看到網路上很熱門的產品，
實際上不一定適合自己的膚質，
而且一般人在購買時也不一定看得懂產品的成分表。

所以我希望設計一個 AI，
可以先了解使用者的膚質、預算和需求，
再去分析不同保養品或化妝品的成分，
最後推薦比較適合的產品。

除了推薦產品之外，
我也希望它可以把產品依照價格和 CP 值分類，
讓使用者可以依照自己的預算選擇。

---

## 2. Input｜AI 會收到什麼？

我希望使用者可以先輸入自己的基本需求。

例如：

- 膚質：油性肌、乾性肌、混合肌、敏感肌
- 目前的皮膚需求：保濕、控油、提亮、舒緩、抗老、痘痘肌等
- 是否容易過敏
- 想找的產品類型：化妝水、精華液、乳液、防曬、粉底液等
- 可以接受的價格範圍
- 是否有不想使用的成分
- 是否重視 CP 值
- 是否偏好專櫃或開架產品

例如：

> 我的膚質是偏油的敏感肌，
> 夏天容易出油和長痘，
> 想找保濕精華液，
> 預算大約 1000 元內，
> 希望成分不要太刺激。

這些資訊就是 AI 的主要 Input。

另外，也可以讓使用者直接輸入：

- 商品名稱
- 商品網址
- 成分表文字
- 保養品成分表圖片

讓 AI 幫忙分析某一個產品適不適合自己。

---

## 3. AI 需要做什麼？

AI 收到使用者的資訊之後，
我希望它先判斷使用者的需求，
再去分析產品的成分與特色。

例如：

使用者是敏感肌，
AI 在分析產品時就要特別注意：

- 是否有較刺激的成分
- 是否有香精
- 是否含有酒精
- 是否有適合舒緩或保濕的成分

如果使用者是油性肌，
就可以優先考慮：

- 質地是否比較清爽
- 是否容易造成厚重感
- 是否有控油相關成分
- 是否適合容易長痘的膚況

而不是所有人都推薦完全相同的產品。

---

## 4. Output｜AI 最後會輸出什麼？

我希望 AI 最後會提供一份個人化的推薦清單。

推薦結果可以分成不同價位：

### 平價區
適合預算比較有限，
但希望找到成分和效果都不錯的產品。

### 中價位區
價格比一般開架產品高一些，
但成分、使用感或品牌表現較完整。

### 高 CP 值區
不一定是最便宜，
而是綜合價格、容量、成分和功能之後，
AI 認為比較值得購買的產品。

### 高階區
例如專櫃或價格較高的產品，
適合願意提高預算的人。

每一項產品我希望 AI 都整理成：

| 項目 | 內容 |
| --- | --- |
| 產品名稱 | 商品名稱 |
| 適合膚質 | 油肌 / 乾肌 / 敏感肌等 |
| 主要功效 | 保濕、控油、舒緩等 |
| 主要成分 | 重要成分與作用 |
| 需要注意的成分 | 可能較刺激或需要留意的成分 |
| 價格區間 | 平價 / 中等 / 高階 |
| CP 值 | AI 根據價格、容量與功能進行比較 |
| 推薦原因 | 為什麼適合這位使用者 |
| 注意事項 | 哪些膚況可能不適合 |

---

## 5. AI 需要哪些資料？

為了完成推薦，
AI 需要參考不同種類的資料。

例如：

- 保養品與化妝品的完整成分表
- 各成分常見的功能
- 不同膚質對產品的需求
- 商品的價格
- 商品容量
- 品牌官方提供的產品資訊
- 使用方式
- 不同產品的分類

如果要計算 CP 值，
還可以加入：

**商品價格 ÷ 商品容量**

再搭配成分、功能以及使用者需求一起判斷，
而不是單純認為越便宜 CP 值就越高。

---

## 6. 實際使用情境

例如今天我要買一瓶精華液。

我的需求是：

- 油性敏感肌
- 容易出油
- 偶爾長痘
- 想增加保濕
- 預算約 1500 元

我就可以把這些資訊告訴 AI。

AI 先分析我的膚質和需求，
接著從產品資料中篩選，
最後分成：

**平價推薦**
→ 500 元以下

**中價位推薦**
→ 500～1500 元

**高 CP 值推薦**
→ 價格與成分表現較平衡的產品

**高階推薦**
→ 1500 元以上

並告訴我每一項產品的主要成分、
適合的原因以及需要注意的地方。

這樣我就不需要每次看到一個商品，
再自己搜尋很多網站慢慢比較。

---

## 7. Input → Output

### Input

使用者膚質  ＋  皮膚需求  ＋  預算  ＋  產品類型  ＋  成分偏好或禁忌

↓

### AI 分析

判斷膚質與需求  
→ 分析產品成分  
→ 篩選可能適合的產品  
→ 比較價格、容量與功能  
→ 分類推薦

↓

### Output

個人化產品推薦清單

包含：

- 平價產品
- 中價位產品
- 高 CP 值產品
- 高階產品

並提供：

**適合膚質＋主要成分＋推薦原因＋價格＋注意事項**

---

## 8. 我為什麼會想要這個 AI？

我自己覺得現在買保養品最麻煩的地方，
不是沒有產品可以選，而是選擇太多。

網路上的評價也常常是某個人覺得很好用，
但那個人的膚質不一定跟自己一樣。

所以我希望這個 AI 不只是告訴我
「現在最熱門的是什麼」，

而是可以先理解我的膚質和預算，
再幫我分析產品到底適不適合我。

我覺得這樣的推薦方式，
會比單純看網紅推薦或排行榜更實用。
